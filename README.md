# 🧪 Workshop: Dynamical Models in Biology

Welcome!  
All exercises for this workshop are provided as interactive Jupyter notebooks that run directly in **Google Colab** — no installation required.

---

## 🚀 How to use these notebooks

1. Click on an **“Open in Colab”** button below  
2. The notebook will open automatically  
3. In Colab, click **Runtime → Run all**  
4. You’re ready to go!

💡 Tip:  
Right-click and select **“Open link in new tab”** to open multiple notebooks at once.
